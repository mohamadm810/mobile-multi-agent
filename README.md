# Mobile Multi-Agent

A lightweight, GitHub Actions-based multi-agent project planner powered by the Gemini API.

## فارسی

برای راهنمای نصب و استفاده، فایل [README_FA.md](README_FA.md) را ببینید.

## Quick start

1. Add `GEMINI_API_KEY` as a GitHub Actions repository secret.
2. Optionally set `GEMINI_MODEL` as a repository variable.
3. Edit `workspace/REQUEST.md` and run the **Run Multi-Agent** workflow, or trigger it manually from Actions.

The initial version produces analysis and planning reports only. It does not execute changes in external projects.
