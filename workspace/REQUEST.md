# درخواست اجرای آزمایشی سامانه

این یک آزمون یکپارچه‌سازی (Integration Smoke Test) برای بررسی اتصال Gemini و هماهنگی هفت نقش ایجنت است، نه درخواست تغییر در یک پروژه واقعی.

هدف:
ارزیابی کیفیت تحلیل و هماهنگی تیم هفت‌ایجنتی همین سامانه بر اساس توضیح زیر.

شرح سامانه:
یک ابزار برنامه‌ریزی چندایجنتی مبتنی بر Python و GitHub Actions که از Gemini API استفاده می‌کند. هفت نقش آن عبارت‌اند از تحلیل‌گر نیازمندی، معمار نرم‌افزار، برنامه‌ریز توسعه، طراح آزمون، بازبین مستقل، ناظر مرکزی و مستندساز. ورودی در workspace/REQUEST.md قرار می‌گیرد و خروجی گزارش در workspace/REPORT.md و وضعیت در workspace/STATE.json ثبت می‌شود.

محدودیت‌های قطعی:
- فقط تحلیل و برنامه‌ریزی؛ هیچ تغییر خودکار در پروژه‌های دیگر انجام نشود.
- هیچ فرمان shell، کد یا عملیات مخرب پیشنهاد یا اجرا نشود.
- فرضیات از واقعیت تفکیک شوند.
- موارد ناقص، ریسک‌ها و آزمون‌های لازم صریح باشند.

معیار پذیرش:
هر هفت نقش باید پاسخ دهند؛ گزارش نهایی باید شامل نقاط قوت، شکاف‌های معماری، ریسک‌های امنیتی، آزمون‌های پیشنهادی و اولویت‌های نسخه بعد باشد. این اجرا صرفاً برای تأیید سلامت اتصال API و گردش کار است.
